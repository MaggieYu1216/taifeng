# 台风一屏通

面向沿海居民的台风实况与分级避险单页网站。

目标是在手机一屏内回答五个问题：

1. 台风叫什么？
2. 现在在哪里？
3. 有多强？
4. 往哪里走？
5. 我现在该做什么？

## 本地查看

这是一个不依赖第三方安装包的静态页面。可以直接打开 `index.html`；为了获得更稳定的浏览器效果，也可以通过本地静态服务器预览。

页面优先读取[浙江省台风路径实时发布系统](https://typhoon.slt.zj.gov.cn/)的台风实况和路径数据。如果官方数据明确表示没有活动台风，页面会如实显示；只有抓取失败时才使用内置演示数据，并在页面顶部醒目标明“演示”。

GitHub Actions 会在代码更新、手动触发以及每 15 分钟定时触发时重新抓取数据、执行自检并发布 GitHub Pages。定时结果直接进入发布文件，不会每 15 分钟制造一次 Git 提交。

## 安全原则

本项目提供信息整理和避险提示，不替代当地政府、气象台、应急管理部门发布的正式命令。涉及停课、停工、停运、转移和避难时，以当地最新通知为准。
