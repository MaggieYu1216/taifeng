# 《台风一屏通》项目计划书

版本：0.1  
日期：2026-11-10  
状态：立项草案

## 一、项目要解决什么问题

台风信息常分散在路径图、新闻、公报和地方通知里。普通居民真正需要的是：打开手机后，不用研究复杂图表，就能立刻知道台风是谁、离哪里近、强度如何、往哪移动，以及自己现在应该做什么。

本项目拟建设一个面向中国沿海居民的手机优先单页网站，用一屏完成核心回答，并允许用户继续下滑查看细节。

一句话目标：**先把最重要的事实和行动放在眼前，再提供细节。**

## 二、服务对象与使用场景

主要服务对象：

- 居住在沿海城市的居民；
- 家中有老人、儿童、孕妇、病人或宠物的人；
- 不熟悉气象术语、只想快速判断该做什么的人；
- 在台风来临前、影响中和离开后查看信息的人。

典型场景：

- 通勤前快速确认是否需要改变行程；
- 家庭提前准备水、食物、药品和充电设备；
- 判断是否需要远离海边、低洼地、危旧房或山坡；
- 收到转移通知后快速查看行动清单和求助入口；
- 网络较慢或短时断网时，仍能看到最后一次成功更新的信息。

## 三、首屏设计：五问一屏答完

手机首屏按以下顺序排布：

### 1. 台风叫什么

- 中文名、英文名、编号；
- 当前状态，例如“台风”“强台风”；
- 最近更新时间，并明确写“数据更新于 14:00”，避免把旧数据当成实时数据。

### 2. 现在在哪里

- 中心经纬度；
- 相对位置，例如“位于厦门东南方向约 420 公里海面”；
- 小地图显示当前点、用户所在城市和警戒范围；
- 不获得用户许可时，不读取精确位置，允许手动选城市。

### 3. 有多强

- 中心附近最大风力、风速、中心气压；
- 用普通话解释，例如“风力很强，室外广告牌和树枝可能被吹落”；
- 同时显示当地正式预警信号，不自行伪造预警级别。

### 4. 往哪里走

- 移动方向、速度；
- 未来 24/48/72 小时路径；
- 预测路径用虚线或锥形范围表示“不确定”，不能画成必然会经过的单线；
- 如有多个预报机构，只突出一个主来源，其他结果放到详情中，避免首屏打架。

### 5. 我该做什么

- 根据用户所在地的**官方预警信号**和**政府应急通知**显示行动卡；
- 首屏只给 3—5 条最紧急、最容易执行的动作；
- 使用大按钮，例如“查看我家准备清单”“查看附近避难场所”“拨打紧急电话”；
- 转移、停课、停工、停运等必须引用当地官方通知，网站不能自行宣布。

## 四、分级应急预案的表达方式

网站必须把以下三类信息分开，不能混为一谈：

1. **台风强度**：热带风暴、强热带风暴、台风、强台风、超强台风，描述台风本身有多强；
2. **气象预警信号**：多数地区使用蓝、黄、橙、红，广东等地另有白色，描述当地可能受到的影响；
3. **政府应急响应**：通常分为四、三、二、一级，一级最高，由政府及防汛抗旱指挥机构综合研判后启动。

第一版居民行动卡按当地正式信号展示，文案草案如下。具体城市上线前，必须由当地有效规定校核：

| 居民行动卡 | 首要目标 | 建议动作（摘要） |
|---|---|---|
| 留意 | 知道变化 | 选好所在城市；关注更新；检查门窗、阳台和排水口；准备充电宝、常用药和饮用水 |
| 准备 | 减少外出风险 | 收回阳台物品；减少海边、河边和山坡活动；车辆离开低洼处；照顾老人儿童；确认官方通知 |
| 避险 | 尽快进入安全状态 | 停止非必要外出；远离玻璃窗和临时搭建物；不要涉水行车；随时准备按通知转移 |
| 紧急 | 保命优先 | 立即执行政府转移或避难命令；不要自行返回危险区；保持电话畅通；遇险拨打 110、119 或 120 |

重要限制：

- 行动卡只是把官方指南翻译成更容易执行的步骤，不代替正式预警和命令；
- 不允许仅凭台风中心风力自动推断某城市预警颜色；
- 不允许把国家级应急响应直接当成某位居民所在地的行动等级；
- 不同省市标准和停课停工规定可能不同，必须按城市配置；
- 台风过后仍需提示积水、漏电、地质灾害和倒伏物风险，不能在台风中心离开后立刻显示“安全”。

## 五、数据方案

### 首选权威来源

- 中央气象台台风网：台风实况、路径预报和公报；
- 中国天气网台风路径页面：公众查看入口，可作为交叉核对来源；
- 国家政务服务平台中的中国气象局灾害预警实时信息；
- 用户所在省、市气象台和应急管理部门发布的本地预警、响应及转移通知。

### 上线前必须完成的数据核验

目前确认了官方公开查看页面，但还没有确认可供本网站长期、稳定、合法自动调用的公开接口。因此开发阶段不能直接抓取网页后就当成正式数据服务。上线前需完成：

1. 确认数据接口的授权、更新频率、使用限制和故障通知方式；
2. 至少用两个权威来源交叉检查关键字段；
3. 每条数据保留来源、发布时间和网站收到时间；
4. 数据超过约定时限未更新时，显眼显示“数据可能已过期”，并提供官方入口；
5. 接口失败时保留最后一次成功数据，但不能继续标为“实时”；
6. 不把预测点写成实况点，不把不同机构、不同时间的数据拼成一条路径。

### 核心字段

- 台风编号、中文名、英文名；
- 实况时间、经度、纬度；
- 最大风速、风力等级、中心气压；
- 移动方向、移动速度；
- 预测点时间、位置、强度及来源；
- 风圈半径（如来源提供）；
- 用户城市的预警信号、发布时间、发布单位、正文链接；
- 当地应急响应、发布时间、发布单位、正文链接；
- 数据更新时间、数据是否过期、接口状态。

## 六、页面结构

单页从上到下分为：

1. **安全状态条**：所在城市、官方预警、更新时间、数据是否正常；
2. **五问首屏**：名称、位置、强度、方向、行动；
3. **路径与影响**：可缩放地图、未来路径、风圈、降雨和影响时间；
4. **我的行动清单**：家中、出行、老人儿童、宠物、车辆等场景；
5. **官方通知**：原文标题、发布单位、发布时间和链接；
6. **求助与避难**：110、119、120、当地热线及避难场所；
7. **说明**：数据来源、免责声明、无障碍设置和隐私说明。

## 七、易用性要求

- 手机优先，主文字清楚，大按钮可单手点击；
- 颜色不能是唯一提示，同时使用文字、图标和形状；
- 重要信息支持普通话朗读；
- 数字旁边给出生活化解释，减少专业术语；
- 地图加载失败时，仍用文字说明位置和移动方向；
- 弱网下先显示文字，再加载地图；
- 页面保存最后一次成功数据，并明显标注时间；
- 支持简体中文；后续可增加繁体中文和常用沿海方言音频；
- 不弹广告，不用制造恐慌的倒计时，不收集与避险无关的个人信息。

## 八、技术方案（第一版）

- 类型：纯前端单页网站；若权威接口需要隐藏密钥或统一转接，再增加一个很小的数据服务；
- 页面：建议使用 TypeScript + React + Vite，便于把信息卡、地图和行动卡拆开维护；
- 地图：选择在中国境内合规、手机端稳定的地图服务；具体供应商在数据和费用核验后确定；
- 数据：统一转成项目自己的标准格式，页面不直接依赖某一家接口的原始格式；
- 缓存：保存最后一次成功数据，设置过期标志；
- 监控：记录接口是否正常、数据是否延迟，不记录居民的精确位置；
- 发布：先做可分享测试版，经过真实手机和台风历史数据演练后再公开。

## 九、开发阶段与交付物

### 阶段 0：立项与安全边界（已完成草案）

- 项目计划书；
- 本地 Git 仓库；
- 风险与数据边界。

### 阶段 1：低保真原型

- 手机首屏线框图；
- 无台风、单台风、多台风、数据过期四种页面状态；
- 四级行动卡文案草案。

### 阶段 2：可用页面

- 完成响应式单页；
- 用固定测试数据展示路径、实况和行动卡；
- 完成大字、色弱、键盘和朗读基本适配。

### 阶段 3：实时数据与地区配置

- 接入经过授权的台风实况及路径数据；
- 接入本地预警和应急通知；
- 建立城市差异配置；
- 完成过期、断网和接口故障处理。

### 阶段 4：演练与上线

- 使用历史台风数据回放；
- 邀请沿海居民试用；
- 请气象或应急专业人员复核关键文案；
- 完成隐私、数据授权和免责声明检查；
- 发布正式版本和维护手册。

## 十、第一版验收标准

- 在常见手机上打开后，不滚动即可看清“五问”的核心答案；
- 用户 10 秒内能说出台风名称、当前位置、强度、方向和首要行动；
- 所有实时数据都显示来源与更新时间；
- 旧数据、接口失败和无台风状态不会误导用户；
- 预警信号、台风强度、应急响应三者不会混淆；
- 不允许网站自行宣布停课、停工、停运或转移；
- 地图失败时，文字信息和行动建议仍可使用；
- 页面在弱网下先呈现关键文字；
- 通过至少一次历史台风全流程演练和一次真人手机试用。

## 十一、主要风险与处理办法

| 风险 | 处理办法 |
|---|---|
| 实时数据延迟或错误 | 显示来源与时间；超时标红；交叉核对；提供官方入口 |
| 不同城市标准不同 | 按城市配置，不能用一套规则覆盖全国 |
| 用户把预测当成事实 | 预测路径使用虚线和范围，并写明“不确定” |
| 颜色造成误读 | 同时显示文字、图标和行动，不只靠颜色 |
| 网络中断 | 保留最后数据并标为旧数据；关键清单可离线查看 |
| 定位侵犯隐私 | 默认手动选城市；精确定位需同意；尽量只在设备本地处理 |
| 建议过度或不足 | 只改写官方指南；关键内容由专业人员复核 |

## 十二、下一步需要确认的产品决定

进入页面制作前，建议确认以下三点：

1. 第一批重点城市，例如先做“福建沿海”或“广东沿海”，不要一开始覆盖全国全部地方规则；
2. 项目正式中文名；
3. 是否需要家中有老人、儿童、孕妇、病人或宠物等个性化行动清单。

## 十三、参考依据

- 中央气象台台风网：https://www.nmc.cn/typhoon/
- 中国天气网台风实时路径：https://typhoon.weather.com.cn/gis/typhoon_p.shtml
- 国家政务服务平台“中国气象局灾害预警实时信息”：https://app.gjzwfw.gov.cn/jmopen/webapp/html5/zhyjssxx/index.html
- 《国家防汛抗旱应急预案》：应急响应分为一、二、三、四级，一级最高；台风灾害由地方政府及防汛抗旱指挥机构组织处置。
- 地方气象灾害预警规定：多数地区台风预警使用蓝、黄、橙、红；广东使用白、蓝、黄、橙、红五级。
